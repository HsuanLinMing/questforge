# QuestForge

> A Python-based text adventure RPG for learning backend systems and AI-assisted gameplay.

---

## 專案介紹（Project Overview）
QuestForge 是一個以 **Python** 為核心的文字冒險 RPG 專案，
目標是在 30 天內完成一個可玩的遊戲系統，並結合 **AI 輔助劇情生成**。

本專案主要練習：
- Python 後端與專案架構設計
- 遊戲狀態與規則引擎
- 資料驅動任務系統（3 段式任務鏈）
- 裝備系統與隨機詞綴
- AI 生成敘事（規劃中）

---

## Current Status
